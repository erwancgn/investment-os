# Compass OS — guide rapide

## Concept

La boussole représente l’arbitrage CIO. Les cinq segments représentent Business, Valuation, Short, Portfolio Fit et Memo CIO. Le symbole doit évoquer un système de décision, jamais une promesse de performance ou une application de courtage.

## Versions

- `compass-os.svg` : master sombre principal ;
- `compass-os-light.svg` : variante claire ;
- `compass-os-monochrome.svg` : usages monochromes ;
- `compass-os-horizontal.svg` : signature avec nom ;
- `app-icons/` : exports iOS, PWA, Apple Touch et favicon.

## Couleurs

- bleu : `#3B82F6` ;
- vert : `#22C55E` ;
- corail : `#F06464`.

## Règles

- conserver une zone libre minimale égale à 12,5 % de la largeur du symbole ;
- ne pas déformer, incliner, recolorer partiellement ni ajouter d’ombre externe ;
- préférer le master sombre sur fond neutre et la variante claire sur interface lumineuse ;
- utiliser la version monochrome lorsque la couleur n’est pas fiable ;
- ne pas ajouter de symbole monétaire, chandelier, fusée ou flèche de performance.
